# Portfólio Mateus Henrique

Site estático responsivo em HTML, CSS e JavaScript. Inclui páginas individuais (cases) do Munduca e Renovo do Nilo.

## Personalizar antes de publicar
- Em `index.html`, substitua `SEU_EMAIL` pelo e-mail profissional.
- Confira texto e tecnologias descritos nos projetos.
- Para as imagens do Nilo, coloque capturas em `assets/nilo/` com os nomes `nilo-home.png` e `nilo-produtos.png` (o case já está preparado para inserção).

## Publicar no GitHub Pages
1. Crie um repositório público (ex.: `portfolio`).
2. Envie os arquivos e pastas para a branch `main`.
3. Settings → Pages → Deploy from a branch → `main` / root.
4. Aguarde o endereço publicado.
